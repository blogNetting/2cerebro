Contradicción abierta: el wiki afirma una cifra concreta para el plan GitHub Pro que no se sostiene en fuente primaria. No la resuelve el lint; queda señalada.

## Qué dicen las notas

Dos notas dan la cifra, y coinciden entre sí:

- [[decisiones]] — «hace falta GitHub Pro (~4 $/mes, cubre todos los repos privados de la cuenta, no es coste por repo)» (entrada del 2026-09-25).
- [[flujo-agentes-runbook]] §2 — «GitHub Pro — 4 $/mes en la fecha de esta comprobación» (2026-09-25).

## Por qué queda abierta

La comprobación del 2026-09-28 no encuentra respaldo en fuente primaria: la página de precios de GitHub ya no lista el plan Pro, y la cifra no es verificable en fuente primaria. Por tanto «~4 $/mes» / «4 $/mes» queda **sin verificar**.

No se elige una cifra: este dato lo decide el usuario, no el lint. **Estado: abierta.**
